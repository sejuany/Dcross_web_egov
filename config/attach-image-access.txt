탈부착 이미지 관리 접속 설정

모바일 로그인에서는 매니저 입력만 표시한다.
PC에서는 매니저 로그인 / 탈부착 관리 선택을 표시한다.

기존 계정의 서버 조회 범위:
- 직원 UA/UC/UU, BITS DC001: 기존 전체 이미지 관리 범위
- KB CB307/CB407: 이전등록, 두 회사 업무에 한정. 로그인 지점을 적용하며
  기존 CB407 지점 1의 전체 지점 조회 예외를 유지한다.
- HANA CB057: 변경등록, CB135(하나캐피탈) 업무에 한정
클라이언트가 회사/신청구분/접수번호를 변경해도 서버 범위를 벗어날 수 없다.
동일 범위를 목록, 원본 사진, 삼송 사진, 업로드에 적용한다.

IP 허용은 기존 AttachImageList.do의 목록을 기본값으로 사용한다.
기존 계정 로그인, 이미지 관리 페이지 직접 접근, 조회/업로드 API 모두 검사한다.
휴대폰 번호로 로그인하는 매니저 업무에는 이 IP 제한을 적용하지 않는다.

운영 환경에서 아래 값을 필요에 맞게 설정한 뒤 서버를 재시작한다.
  ATTACH_IMAGE_ALLOWED_IPS=106.241.185.122,221.161.230.33,220.65.183.0/24
위 값은 형식 예시다. 지정하면 기본 목록을 대체한다.
정확한 IPv4/IPv6 주소 및 IPv4 /24 네트워크를 지원한다.
기본 목록에는 로컬 개발을 위한 127.0.0.1, ::1도 포함된다.

리버스 프록시를 사용하는 경우:
  ATTACH_IMAGE_TRUSTED_PROXIES=127.0.0.1,::1
이는 실제 Java 서버로 연결하는 프록시의 전송 주소이며 고객 허용 IP가 아니다.
다른 프록시를 사용하면 실제 프록시 주소만 추가한다.
프록시는 X-Forwarded-For 또는 X-Real-IP를 정확하게 설정해야 한다.
신뢰 목록에 없는 연결의 전달 헤더는 무시한다.
X-Forwarded-For는 오른쪽부터 신뢰 프록시를 제거해 최초 비신뢰 주소를 사용한다.
프록시 주소를 고객 허용 IP에 추가하여 모든 접속을 허용하지 않는다.

application 설정 키로도 지정할 수 있다:
  attach.images.allowed-ips
  attach.images.trusted-proxies

운영 실제 프록시/계정/DB를 사용한 검증은 별도로 필요하다.
